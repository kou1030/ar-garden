# ポケット・ロボラボ

公開URL https://kou1030.github.io/ar-garden/

- **ロボットを召喚** `play.html`。背面カメラでオリジナルのマーカーを映すと、AR.jsでロボット R-01 を机上に重ねる。方向ボタンを押している間は移動。ジャンプ、手を振る、コア開放ができる。PCの操作プレビューでは矢印キーも使用可能。
- **ロボットに変身** `face.html`。MindAR.js 1.2.5 が内カメラで顔を追い、口の開きに連動して装甲を展開。発光コアとギアが現れる。反応感度と色を変更できる。
- **召喚マーカー** `marker.html`。既存のオリジナルPNGとPATTを使用。印刷時は白い余白を残して、黒枠外寸約10 cmを目安にする。
- **提出用レポート** `report.html`。実機画像と氏名、検証結果を追記してPDFへ保存。`report.pdf` は追記前の版。

スマートフォンからはHTTPSのSafari / Chromeで開き、選んだモードでカメラを許可。顔フィルター初回はMediaPipeの公開モデルとWASMを取得する。映像と顔データはブラウザ内で処理する。動作確認用のカメラなしプレビューも各モードにある。

マーカーの画像検証は `diagnostics.html`。実機ではカメラの選択と権限、マーカーの認識と再追従、方向とアクション、顔の位置合わせ、口を開閉した際の反応を確認する。

A-Frame 1.6.0、AR.js 3.4.7、MindAR.js 1.2.5を使用。ライセンスは `vendor/` に同梱。静的サイトでビルド不要。ローカルでは `python -m http.server 8000` を起動し、http://localhost:8000/ を開く。
